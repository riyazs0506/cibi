# Premium corporate refinement

## Goal

Make the Cibi Solar site feel composed, credible, and easy for a prospective client to scan. Preserve the existing solar finder, catalogue, routes, accessibility support, and Cibi branding.

## Layout system

All homepage sections share the existing `container-x` width and consistent section padding. Section headings use one editorial two-column alignment: the title anchors left while supporting copy or a secondary action anchors right. On small screens, these columns stack in reading order.

The hero remains the primary visual moment. It uses restrained type, a dark image treatment, one primary enquiry action, one secondary product action, and a compact trust strip directly below. No client names, installation counts, ratings, or claims are added because they have not been supplied.

## Content hierarchy

The page order is: hero and trust cues, audience solutions, company introduction, product ecosystem, system finder, service process, and final enquiry action. Each section has one purpose and a single visual density, preventing competing calls to action.

The product ecosystem retains an asymmetric panel-led feature card with four supporting cards. The system finder stays a focused dark section, visually separating the interactive decision from the surrounding editorial content.

## Shared UI

Use deep navy, warm white, muted slate, and sunlight yellow throughout navigation, buttons, footer, cards, and metadata assets. Keep borders fine, shadows soft, and corners modest. Preserve visible focus rings, reduced-motion behavior, real link/button semantics, and responsive mobile CTA access.

## Verification

Run TypeScript and the static production build. Check the homepage and product catalogue at desktop and 390px widths. Confirm there is no horizontal overflow, no broken images, navigation links work, the mobile menu closes after selecting a route, and a complete solar-finder flow produces recommendations.
