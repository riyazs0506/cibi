# Imagery

All 23 illustrations are generated by `scripts/generate-images.mjs` and total
about 230 KB — smaller than a single mid-sized JPEG. They are **vector
stand-ins for real photography**, drawn from one parametric template so the
whole set shares a light source, palette and perspective.

```bash
npm run assets    # regenerates every image and the social card
```

## Replacing with photography

Drop a real photo at the same path with the same filename. No component
changes, no data changes. Filenames are already descriptive for SEO.

Every `<img>` on the site has explicit `width`/`height` so nothing shifts as
images load, and everything below the fold is `loading="lazy"`. Keep those
attributes accurate if you change aspect ratios.

### What each slot expects

| Path | Size | Aspect | Used on |
|---|---|---|---|
| `hero-rooftop-solar-system.svg` | 720 × 560 | 9:7 | Home hero — **the LCP element**, never lazy-load it |
| `about-solar-installation.svg` | 640 × 480 | 4:3 | Home about section, About page |
| `category-*.svg` (5) | 640 × 420 | 3:2 | Category cards, category page headers |
| `product-*.svg` (15) | 640 × 420 | 3:2 | Product cards, product pages, finder results |
| `cibi-solar-logo.svg` | 512 × 512 | 1:1 | `Organization` structured data only |
| `og-cibi-solar.png` | 1200 × 630 | 1.91:1 | Open Graph / Twitter card |

The product filenames must match the `image` field in `data/products.ts`
exactly. The generator's `productArt` list and that data file are the two places
to keep in step.

### If you switch to photographs

- Export **WebP or AVIF** with a JPEG fallback; at these dimensions expect
  60–120 KB each rather than the current ~10 KB.
- Keep the 3:2 product crop — the cards assume it.
- Shoot or crop on a light, uncluttered ground. The cards sit on a very soft
  blue-to-white gradient, and busy backgrounds fight it.
- Soft, natural light. The brief explicitly rules out flare, neon and heavy
  edits.
- Update the `alt` text in `data/categories.ts` and `data/products.ts` to
  describe the actual photograph.

## The generator

`scripts/generate-images.mjs` has five renderers — `panelArt`, `inverterArt`,
`batteryArt`, `waterHeaterArt`, `streetLightArt` — plus the hero and about
scenes. Each takes a label, a sub-label and an accent colour, so adding a
product means adding one line to the `productArt` array.

Colours mirror the tokens in `app/globals.css`. If the palette changes there,
update the `C` object at the top of the generator and rerun `npm run assets`.

## Icons

Icons are **not** images. They are inline SVG paths in
`components/ui/Icon.tsx`, hand-drawn on a shared 24 × 24 grid at 1.6 stroke
width. This ships a few hundred bytes instead of an icon package, and keeps the
whole set on one visual weight. Add new ones to the `paths` map and the
`IconName` union.
